# Cadence

Cadence is an offline Android pedometer. It counts steps from the phone's
sensors and estimates distance, walking calories, basal metabolic rate (BMR)
and resting metabolic rate (RMR) from your profile. All data stays on the device.

## Build

```sh
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
```

On Windows, use `gradlew.bat` instead of `./gradlew`.
